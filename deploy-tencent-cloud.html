🟢 方案 A：CloudBase 云开发静态托管 推荐

腾讯云 CloudBase 提供静态网站托管服务，自带 CDN 加速和 HTTPS，默认域名无需备案。

✅ 优势：免费额度大（1GB 存储 + 5GB 流量/月）、自带 CDN、自动 HTTPS、CLI 一键部署、默认域名免备案
1

注册 / 登录腾讯云账号

打开 https://cloud.tencent.com，点击右上角「注册」或「登录」。

  • 支持微信扫码登录、邮箱注册、企业微信登录
  • 新用户注册后建议完成实名认证（个人认证即可，在「账号中心 → 实名认证」中操作）
  • 实名认证后才能使用 CloudBase 服务
2

开通 CloudBase 云开发

打开 CloudBase 控制台：

  1. 首次进入会提示「开通服务」，点击「立即开通」
  2. 选择按量付费计费模式（有免费额度，不会产生费用）
  3. 创建一个新环境：
    • 环境名称：填 meal-reminder（随意，英文即可）
    • 环境来源：选择「空白应用」
    • 计费方式：按量付费（包年包月也可以，都有免费额度）
  4. 点击「开通」，等待约 10-30 秒环境创建完成
📝 创建完成后，记下你的环境 ID（形如 meal-reminder-xxxxx），后续部署会用到。
3

开启静态网站托管

在 CloudBase 控制台中：

  1. 点击左侧菜单「静态网站托管」
  2. 首次使用会提示开通，点击「立即开通」
  3. 等待开通完成（约 1 分钟）
开通后你会看到一个默认访问域名，格式类似：
https://meal-reminder-xxxxx.tcloudbaseapp.com
这个域名就是你的 APP 公网地址，自带 HTTPS，无需备案！
4

上传网站文件（方式一：控制台上传）

最简单的方式，直接在控制台拖拽上传：

  1. 在「静态网站托管」页面，点击「上传文件」
  2. 将以下文件全部拖入上传区域（或点击选择文件）：
    • index.html — 主页面
    • manifest.json — PWA 清单
    • sw.js — Service Worker
    • icon-192.png — 应用图标
    • icon-512.png — 高清图标
    • icon-maskable-512.png — 适配图标
    • apple-touch-icon.png — Apple 图标
    • favicon-32.png — 网页图标
  3. 上传路径选择根目录 /
  4. 点击「确定上传」
5

设置索引文档

上传完成后，需要设置默认首页：

  1. 在「静态网站托管」页面，点击「基础配置」标签
  2. 找到「索引文档」，填入 index.html
  3. 找到「错误文档」，也填入 index.html（这样任何路径都能正常打开 APP）
  4. 点击「保存」
6

验证访问 🎉

现在打开你的默认域名：

# 在浏览器中打开这个地址 https://meal-reminder-xxxxx.tcloudbaseapp.com

如果看到饭点打卡 APP 的首页，说明部署成功！🎉

📱 安装到手机：用手机浏览器打开此地址，然后「添加到主屏幕」即可像原生 APP 一样使用。
🔵 方案 B：COS 对象存储静态网站托管

使用腾讯云对象存储（COS）托管静态网站，适合需要更多控制权的用户。

⚠️ 注意：COS 静态网站托管的默认域名（cos-website.region.myqcloud.com）仅支持 HTTP。 如需 HTTPS 和自定义域名，需要绑定已 ICP 备案的域名 + 配置 CDN。
1

登录腾讯云��进入 COS 控制台

打开 COS 控制台，首次使用需开通服务（免费开通）。

2

创建存储桶

  1. 点击左上角「创建存储桶」
  2. 填写信息：
    • 名称：meal-reminder-app（会自动加 APPID 后缀）
    • 地域：选择离你最近的（如 ap-beijing 北京 / ap-shanghai 上海 / ap-guangzhou 广州）
    • 访问权限：选择「公有读私有写」（重要！否则网页无法公开访问）
  3. 其他选项保持默认，点击「下一步」 → 「创建」
存储桶名称：meal-reminder-app-1250000000（你的 APPID）
访问域名：https://meal-reminder-app-1250000000.cos.ap-beijing.myqcloud.com
地域：ap-beijing（北京）
3

上传网站文件

  1. 进入刚创建的存储桶，点击「上传文件」
  2. 将所有 APP 文件拖入上传区域（index.html、manifest.json、sw.js、所有图标 png）
  3. 文件权限选择「继承存储桶权限」（公有读）
  4. 点击「上传」
💡 上传后可以直接通过 https://存储桶名.cos.region.myqcloud.com/index.html 访问，但此时还没有静态网站托管功能（错误页面跳转等）。
4

开启静态网站托管

  1. 在存储桶详情页，点击左侧「权限管理」→「静态网站」
  2. 点击「编辑」，开启静态网站
  3. 设置：
    • 索引文档（默认首页）：index.html
    • 错误文档（404 页面）：index.html
    • HTTPS 选项：如已配置自定义域名+证书，可强制 HTTPS
  4. 点击「保存」
保存后会生成一个静态网站访问域名：
https://meal-reminder-app-1250000000.cos-website.ap-beijing.myqcloud.com
5

（推荐）配置 CDN 加速 + HTTPS

COS 默认域名不支持 HTTPS，需通过 CDN 实现 HTTPS 访问：

  1. 进入 CDN 控制台，点击「添加域名」
  2. 填写配置：
    • 加速域名：填你已备案的域名（如 meal.yourdomain.com）
    • 源站类型：选择「COS 源」，选择刚才创建的存储桶
    • 回源协议：HTTPS
    • 加速类型：CDN 全球加速
  3. HTTPS 配置（在下一步域名审核通过后设置）：
    • 申请免费证书：在 CDN 域名管理 → HTTPS 配置 → 「配置证书」→ 「免费证书」
    • 开启「强制跳转 HTTPS」
  4. 在域名 DNS 服务商添加 CNAME 解析记录：
    记录类型：CNAME
    主机记录：meal（或你设置的子域名前缀）
    记录值：CDN 分配的 CNAME 地址（如 meal.cdn.dnsv1.com）
  5. 等待 DNS 生效（通常几分钟到几小时）
⚠️ ICP 备案要求：使用自定义域名访问腾讯云 CDN，该域名必须已完成 ICP 备案。备案流程在腾讯云控制台「备案」中办理，通常需要 7-20 个工作日。
⚡ CLI 自动化部署（推荐进阶用户）

使用命令行工具一键部署，后续更新代码只需一条命令。

📦 CloudBase CLI 部署（方案 A 对应） ▶

使用 @cloudbase/cli 工具，一行命令部署到 CloudBase 静态托管。

① 安装 CLI 工具

# 使用 npm 全局安装（需 Node.js 14+） > npm install -g @cloudbase/cli # 验证安装 > tcb --version # 应输出类似：@cloudbase/cli 2.x.x

② 登录腾讯云

> tcb login # 浏览器会自动打开腾讯云授权页面 # 点击「同意授权」即可完成登录

③ 部署到 CloudBase

# 进入项目目录 > cd C:\Users\lwqhp\WorkBuddy\2026-07-30-13-47-04\meal-reminder-app # 部署所有文件到静态托管 > tcb hosting deploy ./ --env meal-reminder-xxxxx # ↑ 替换为你的环境 ID # 指定部署到根目录 > tcb hosting deploy ./ --env meal-reminder-xxxxx --dir /

④ 后续更新

# 修改代码后，重新执行部署命令即可 > tcb hosting deploy ./ --env meal-reminder-xxxxx
✅ CloudBase CLI 部署后直接通过 https://环境ID.tcloudbaseapp.com 访问，自带 HTTPS + CDN，无需额外配置。
📦 COSCMD 命令行部署（方案 B 对应） ▶

使用 coscmd 工具批量上传文件到 COS 存储桶。

① 获取 API 密钥

  1. 打开 API 密钥管理
  2. 点击「新建密钥」，获取 SecretId 和 SecretKey
  3. 记录好这两个值（只显示一次）

② 安装 COSCMD

# 使用 pip 安装（需 Python 3.6+） > pip install coscmd # 验证安装 > coscmd --version

③ 配置 COSCMD

> coscmd config -a 你的SecretId -s 你的SecretKey -b meal-reminder-app-1250000000 -r ap-beijing # ↑ SecretId ↑ SecretKey ↑ 存储桶名-APPID ↑ 地域

④ 上传文件

# 进入项目目录 > cd C:\Users\lwqhp\WorkBuddy\2026-07-30-13-47-04\meal-reminder-app # 上传当前目录所有文件到存储桶根目录 > coscmd upload -r ./ / # -r 表示递归上传（包括子目录） # 上传单个文件 > coscmd upload index.html /

⑤ 后续更新

# 修改代码后，重新上传即可 > coscmd upload -r ./ /
🔄 GitHub Actions 自动部署（CI/CD） ▶

将代码推送到 GitHub 后，每次 push 自动部署到腾讯云，无需手动操作。

① 在 GitHub 仓库设置 Secrets

进入 GitHub 仓库 → Settings → Secrets and variables → Actions，添加以下 Secrets：

TENCENT_SECRET_ID = 你的腾讯云 SecretId
TENCENT_SECRET_KEY = 你的腾讯云 SecretKey
TCB_ENV_ID = meal-reminder-xxxxx（CloudBase 环境 ID）

② 创建 Workflow 文件

在项目根目录创建 .github/workflows/deploy.yml：

name: Deploy to Tencent CloudBase on: push: branches: [ main ] jobs: deploy: runs-on: ubuntu-latest steps: - uses: actions/checkout@v4 - name: Setup Node.js uses: actions/setup-node@v4 with: node-version: 18 - name: Install CloudBase CLI run: npm install -g @cloudbase/cli - name: Deploy to CloudBase env: TENCENT_SECRET_ID: ${{ secrets.TENCENT_SECRET_ID }} TENCENT_SECRET_KEY: ${{ secrets.TENCENT_SECRET_KEY }} TCB_ENV_ID: ${{ secrets.TCB_ENV_ID }} run: | tcb login --secretId "$TENCENT_SECRET_ID" --secretKey "$TENCENT_SECRET_KEY" tcb hosting deploy ./ --env "$TCB_ENV_ID"

③ 推送代码触发部署

> git add -A > git commit -m "deploy: update app" > git push # GitHub Actions 会自动执行部署
🌐 绑定自定义域名

如果你想用自己的域名访问（如 meal.yourname.com），按以下步骤操作。

⚠️ 重要：在中国大陆服务器上使用自定义域名，该域名必须完成 ICP 备案。未备案域名无法绑定。备案在腾讯云控制台「备案」中办理。
1

在 CloudBase 中绑定域名

  1. 进入 CloudBase 控制台 → 静态网站托管 → 「基础配置」
  2. 找到「域名管理」，点击「添加域名」
  3. 输入你的域名（如 meal.yourname.com）
  4. 系统会生成一个 CNAME 值，复制它
2

配置 DNS 解析

到你的域名 DNS 服务商（如腾讯云 DNSPod、阿里云云解析等）添加记录：

记录类型：CNAME
主机记录：meal
记录值：CloudBase 给你的 CNAME 地址
TTL：600（默认即可）
3

配置 HTTPS 证书

  1. 在域名管理页面，点击已添加域名旁的「HTTPS 配置」
  2. 选择「申请免费证书」（腾讯云提供免费 DV 证书，有效期 1 年）
  3. 按提示完成域名验证（DNS 验证，添加一条 TXT 记录）
  4. 证书签发后（约 5-15 分钟），开启「强制 HTTPS 跳转」
✅ 配置完成后，通过 https://meal.yourname.com 即可访问你的 APP。

❓ 常见问题
Q：必须实名认证吗？ ▶

是的，腾讯云所有服务都要求完成实名认证后才能使用。个人认证只需身份证，几分钟即可完成。

Q：CloudBase 默认域名需要备案吗？ ▶

不需要。CloudBase 提供的默认域名（xxx.tcloudbaseapp.com）属于腾讯云自有域名，已备案，你可以直接使用。只有绑定自己的域名时才需要 ICP 备案。

Q：PWA 的 Service Worker 在 HTTPS 下才能工作？ ▶

是的，Service Worker 和摄像头 API 都要求 HTTPS 环境。CloudBase 默认域名自带 HTTPS，无需额外配置。COS 默认域名仅 HTTP，需配置 CDN + 自定义域名 + 证书才能实现 HTTPS。

Q：部署后如何更新 APP？ ▶

三种方式更新：

  • 控制台上传：删除旧文件，重新上传新文件
  • CLI 命令：tcb hosting deploy ./ --env 环境ID（推荐）
  • CI/CD 自动：配置 GitHub Actions 后，每次 push 自动部署
Q：手机上怎么安装为 APP？ ▶

iPhone (Safari)：打开网址 → 点击底部「分享」按钮 → 选择「添加到主屏幕」→ 点击「添加」

Android (Chrome)：打开网址 → 点击菜单(⋮) → 选择「添加到主屏幕」→ 点击「安装」

安装后桌面会出现应用图标，点击直接全屏打开，体验和原生 APP 一致。

Q：CloudBase 和 COS 选哪个？ ▶

简单总结：

  • 选 CloudBase：想快速上线、不需要自定义域名、想要自带 CDN 和 HTTPS → 90% 的人选这个
  • 选 COS：已有备案域名、需要 CDN 精细控制、企业级部署需求
